# 수학 탐구 위키

분야 제한 없이 질문을 만들고, 계산하고, 증명하고, 반례를 찾는 개인 수학 연구 공간입니다. 연구 결과는 Markdown으로 남기며, 여러 에이전트가 독립적으로 탐구하고 서로 검토합니다.

**[위키 시작하기](wiki/Home.md)** · [웹뷰어 사용법](wiki/Viewer.md) · [연구 노트 목록](wiki/ResearchNotes.md) · [열린 질문](wiki/Questions.md) · [분야별 목록](wiki/Topics.md) · [연구 기록](wiki/ResearchLog.md)

## 웹뷰어 열기

**[open_wiki.cmd](open_wiki.cmd)를 더블클릭**하면 로컬 서버와 기본 브라우저를 엽니다. Python 3.10 이상만 있으면 되고 추가 설치 없이 오프라인에서도 수식과 Markdown을 읽을 수 있습니다. 서버 창에서 `Ctrl+C`를 누르면 종료합니다.

연구 노트의 검색, 분야·검토 필터, 점수 높은순·낮은순·최근 수정순·제목순 정렬을 지원합니다. 새 `research/<작업 ID>/note.md`와 같은 폴더의 `meta.json`을 자동으로 읽습니다. 점수는 노트별 메타데이터에서 관리하며 Markdown 목록을 수동 정렬하지 않습니다. 사용법과 평가 양식은 [웹뷰어 문서](wiki/Viewer.md)에 있습니다.

## 운영 방식

1. 에이전트에게 질문과 고유한 작업 ID를 지정합니다.
2. 각 에이전트는 `research/<작업 ID>/`에서 노트와 계산 코드를 작성합니다.
3. 다른 에이전트가 증명, 가정, 경계 사례, 반례를 검토합니다.
4. 진행을 조율하는 에이전트가 검토 결과와 위키 목록을 갱신합니다.

증명과 계산 증거는 구분합니다. 자율 탐구는 새로운 질문을 자유롭게 고른다는 뜻이며, 알려진 결과를 새로운 발견으로 주장하지 않습니다. 세부 작성 규칙은 [연구 규약](wiki/Conventions.md)과 [에이전트 지침](AGENTS.md)에 있습니다.

## 에이전트에 줄 시작 지시 예시

```text
AGENTS.md와 wiki/Conventions.md를 읽어라.
작업 ID: 2026-10-29-number-theory-01
자유롭게 정수론 질문 하나를 선택해 research/2026-10-29-number-theory-01/에서 탐구하라.
증명, 추측, 계산 증거를 구분하고 재현 방법을 남겨라.
공용 색인은 직접 수정하지 말고, 작업 폴더의 handoff.md에 요약과 추가할 링크를 남겨라.
```

서로 다른 에이전트에는 서로 다른 작업 ID를 줍니다. 검토를 맡길 때는 [검토 양식](templates/review.md)을 사용합니다. 에이전트 실행과 외부 웹 게시는 별도이며, 로컬 열람은 위 웹뷰어로 할 수 있습니다.

## 로컬 확인

Python 3 표준 라이브러리만 사용합니다. 저장소 루트에서 실행합니다.

```powershell
python tools/check_wiki.py
python research/2026-10-29-finite-differences/verify.py
```

첫 명령은 Markdown의 로컬 링크와 이미지 경로를 검사합니다. 두 번째 명령은 첫 연구 노트의 항등식을 유한 범위에서 검산합니다. 검산의 통과가 일반적인 증명을 대신하지는 않습니다.
