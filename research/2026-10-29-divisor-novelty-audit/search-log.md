# 검색 기록

- 날짜: 2026-10-29
- 목적: 일반 하한의 [고정 명제](claim.md)가 직접 선행연구에 포함되는지 조사.
- 방법: 공개 웹 검색 → 발견한 공식 서지/저자 원문/출판사 원문 열기 → 규칙과 적용 범위 대조.
- 제한: 논문 제목이나 검색 추출문만으로 읽지 않은 본문의 범위를 추정하지 않았다.
- 문헌별 확인 상태: [sources.json](sources.json).

## 얻은 것

- 2016년 c=2 원문과 2017년 후속 논문의 확실한 서지.
- 유한 뺄셈집합, SALIQUOT, i-MARK의 실제 정의와 비교할 정리.
- 2025/2026년 다산 약수 게임의 원문. 산의 수 m과 최소 허용 약수 c가 다른 매개변수임을 확인.

## 얻지 못한 것

- 2017년 pp.49–60의 공개 본문.
- 그 논문이 모든 c의 유한 좌표 닫힘을 포함한다거나 포함하지 않는다는 판정.
- 같은 결과가 다른 용어로 존재하지 않는다는 보장.

구체적인 검색 실패는 접근 시점의 결과이다. 논문이 공개되지 않았거나 존재하지 않는다는 뜻이 아니다.
접속 실패 주소, 복사본의 검색 추출문, 제목이 같은 별개 논문을 본문 확인으로 계산하지 않았다.
