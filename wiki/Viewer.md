## 열기와 종료

저장소 루트의 [open_wiki.cmd](../open_wiki.cmd)를 더블클릭한다. Python 3.10 이상이 있으면 별도 패키지 설치 없이 로컬 서버를 시작하고 기본 브라우저를 연다. 프로젝트에 포함된 수식·Markdown 렌더링 파일을 사용하므로 실행 중 인터넷 연결은 필요하지 않다.

서버를 실행한 창을 열어 둔다. 종료할 때 그 창에서 `Ctrl+C`를 누른다. 같은 위키를 이미 실행했다면 실행 파일을 다시 열어 기존 서버를 이용한다. 다른 프로그램이 기본 포트를 쓰고 있으면 다음 포트로 이동한다.

PowerShell 또는 CMD에서 직접 실행할 수도 있다.

```powershell
python tools/serve_wiki.py --open
```

기본 주소는 `http://127.0.0.1:8765/`이며 실제 주소는 서버 창에 표시된다. 다른 포트가 필요하면 `--port 9000`, 임의의 빈 포트는 `--port 0`을 사용한다. 서버는 현재 컴퓨터에서 접속하는 읽기 전용 뷰어다.

## 화면 기능

- 연구 노트: 점수 높은순·낮은순, 최근 수정순, 제목순으로 정렬한다. 점수 정렬에서 동점은 작업 ID순, 미평가는 마지막이다.
- 검색: 노트 제목, 작업 ID, 분야, 요약, 신규성 설명을 검색한다. 본문 전체 검색은 아니다.
- 필터: 분야와 독립 검토 상태를 함께 선택한다.
- 문서 읽기: Markdown, 표, 코드, 수식과 문서 간 상대 링크를 표시한다. 오른쪽 목차에서 해당 절로 이동할 수 있다.
- 성과 평가 근거: 연구 노트 아래의 펼침 항목에서 점수의 이유와 재평가 조건을 확인한다.
- 모든 문서: 위키, 연구·검토·계산 기록, 작성 양식을 찾아본다.
- 원문: 문서의 Markdown 원본과 연결된 검증 코드·평가 JSON을 확인한다.

파일을 수정한 뒤 15초 안에 자동 반영된다. 탭을 보고 있을 때 변경을 확인하며, `새로고침` 버튼으로 즉시 다시 읽을 수 있다. 자동 반영 시 현재 읽는 문서의 스크롤 위치를 최대한 유지한다. 외부 링크는 새 탭으로 열리고 외부 이미지는 자동 다운로드하지 않는다.

## 노트와 평가 정보 추가

새 연구 폴더의 `note.md`를 자동으로 찾는다. 별도의 중앙 목록 등록이나 점수순 파일 재배치는 필요 없다. 점수는 같은 폴더의 `meta.json`에 기록한다. [평가 메타데이터 양식](../templates/meta.json)을 복사해 작성한다.

```text
research/
  YYYY-MM-DD-topic-id/
    note.md
    meta.json
    verify.py
```

- `score`: 0–100 정수. 미평가는 `null`이며 0점과 다르다.
- `summary`: 노트 목록에서 보여 줄 짧은 요약.
- `novelty`: 선행 연구 대비 신규성 확인 상태.
- `evaluation_status`, `assessed_at`, `assessor`, `scoring_version`: 평가 상태, 평가일, 평가자, 기준 버전.
- `rationale`: 평가 근거를 문자열 목록으로 기록한다.
- `reassessment`: 재평가 조건.
- `history`: 점수 변경 시 `date`, `before`, `after`, `reason`을 가진 기록을 추가한다.

제목·분야·작성일·수정일·독립 검토 상태는 `note.md` 상단에서 읽는다. 점수와 평가 근거의 원본은 노트별 `meta.json` 한 곳이다. JSON이 잘못되면 목록에 경고를 표시하고 해당 노트는 미평가로 표시한다. `meta.json`이 없어도 노트는 미평가 상태로 나타난다.

## 개발 확인

```powershell
python -m unittest discover -s tests -p "test_*.py"
node --test tests/viewer_model.test.mjs
python tools/check_wiki.py
```

사용 시 Node.js는 필요 없다. 위 두 번째 명령은 정렬·필터의 개발용 검증이다. 렌더링 에셋을 다시 받아야 할 때만 `python tools/vendor_viewer_assets.py`를 실행한다. 이 복원 작업에는 인터넷 연결이 필요하며 고정 버전의 무결성을 검사한다. [외부 라이브러리와 라이선스](../viewer/THIRD_PARTY.md)
